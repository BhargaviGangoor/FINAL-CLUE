## 🚀 Deployment Instructions for KoboToolbox

1. **Upload XLSForm**:
   - Go to your [KoboToolbox](https://kf.kobotoolbox.org/) dashboard.
   - Click **New** &rarr; **Upload an XLSForm**.
   - Select the respective route file (e.g., `PATH1_FINAL_ODK.xlsx`, `PATH2_FINAL_ODK.xlsx`, `PATH3_FINAL_ODK.xlsx`, or `PATH4_FINAL_ODK.xlsx`).

2. **Upload Media Attachments**:
   - In your project settings on KoboToolbox, navigate to **Form** &rarr; **Form Media**.
   - Upload the media files from the respective route's `media/` folder (e.g., `engine_sound.mpeg`, `aiml.jpeg`, `challenge.jpeg`, `morse.jpeg`).

3. **Deploy & Collect**:
   - Click **Deploy**.
   - Download form to **KoboCollect** on mobile devices for the event!
